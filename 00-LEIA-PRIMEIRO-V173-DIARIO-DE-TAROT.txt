DIVINA BRUXA · V173 · DIÁRIO DE TAROT
=====================================

O QUE ESTA VERSÃO ENTREGA

1. Nova página pública:
   diario-de-tarot.html

2. Gerador local de fichas com quatro modelos:
   - leitura de uma carta;
   - leitura de três cartas;
   - estudo de uma carta;
   - revisão de uma leitura antiga.

3. Cada modelo possui:
   - versão essencial;
   - versão completa;
   - orientação para papel ou impressão;
   - orientação para nota ou diário digital;
   - botão para copiar;
   - botão para imprimir somente a ficha;
   - acesso ao Diário privado já existente no aplicativo.

4. Conteúdo editorial:
   - oito campos essenciais de um registro útil;
   - método em cinco movimentos;
   - exemplo fictício de uma carta;
   - orientação para papel, nota digital e Diário da Divina Bruxa;
   - seis erros que retiram contexto;
   - cinco dúvidas frequentes;
   - duas referências sobre aprendizagem e revisão.

5. Integração com:
   - busca completa do portal: 125 destinos;
   - sitemap: 126 páginas;
   - plano de estudo em 30 dias;
   - Escola do Tarot;
   - Guias para começar.

COMO INSTALAR PELO GITHUB NO CELULAR

1. Abra o repositório divinabruxa/divinabruxa.github.io.
2. Entre na raiz da branch Principal/main.
3. Toque em Adicionar arquivo > Carregar arquivos.
4. Selecione TODOS os 13 arquivos soltos deste pacote.
5. Confirme que os arquivos aparecem diretamente na raiz.
   Não crie uma pasta chamada V173 e não envie apenas o ZIP.
6. Confirme a substituição dos 6 arquivos existentes.
7. Grave as alterações e aguarde a publicação do GitHub Pages.
