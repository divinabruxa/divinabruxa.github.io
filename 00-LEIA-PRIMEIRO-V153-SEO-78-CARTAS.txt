COMO INSTALAR PELO IPHONE
============================================================

1. Baixe o arquivo:
   DIVINA-BRUXA-V153-SEO-78-CARTAS.zip

2. Abra o aplicativo Arquivos do iPhone e toque uma vez no ZIP
   para descompactar.

3. Entre no GitHub e abra o repositório do site na pasta principal,
   a mesma tela em que aparecem index.html, app.js e sw.js.

4. Toque em Add file > Upload files.

5. Selecione TODOS os 85 arquivos que estão dentro da pasta
   descompactada.

6. Confirme que os arquivos serão enviados diretamente para a raiz.
   Não crie nenhuma pasta nova.

7. Use esta mensagem no commit:
   Instala V153 SEO das 78 cartas

8. Confirme o upload e aguarde a publicação do GitHub Pages.

IMPORTANTE
- Não envie o arquivo ZIP para dentro do repositório.
- Não apague os outros arquivos do site.
- Quando o GitHub avisar que alguns nomes já existem, isso é correto:
  escolha substituir/atualizar os arquivos.
- O pacote tem menos de 100 arquivos e foi preparado para um único
  envio pelo GitHub.
