============================================================

   DIVINA-BRUXA-V154-PORTAIS-PUBLICOS-GOOGLE.zip

   para descompactar.

3. Entre no GitHub e abra o repositório do site na pasta principal,
   a mesma tela em que aparecem index.html, app.js e sw.js.

4. Toque em Add file > Upload files.

5. Selecione TODOS os 12 arquivos que estão dentro da pasta
   descompactada.

6. Confirme que os arquivos serão enviados diretamente para a raiz.
   Não crie nenhuma pasta nova.

7. Use esta mensagem no commit:
   Instala V154 portais públicos para Google

8. Confirme o upload e aguarde a publicação do GitHub Pages.

- Não envie o arquivo ZIP para dentro do repositório.
- Não apague os outros arquivos do site.
- Quando o GitHub avisar que alguns nomes já existem, isso é correto:
  escolha substituir/atualizar os arquivos.
- Os arquivos novos devem ficar ao lado do index.html.

PRÓXIMO PASSO: GOOGLE SEARCH CONSOLE
============================================================

ESTA V154 PREPARA O SITE, MAS AINDA NÃO FAZ A VERIFICAÇÃO.

Não foi colocado nenhum código falso ou provisório. O Google cria
um arquivo ou uma meta tag exclusiva para a proprietária do site.

Depois que a V154 estiver publicada:

1. Abra:
   https://search.google.com/search-console/

2. Adicione uma propriedade do tipo “Prefixo do URL” usando
   exatamente:
   https://divinabruxa.com.br/

3. Escolha um destes métodos:

   A) Arquivo HTML — recomendado para o seu modo de instalação
      - Baixe o arquivo googleXXXXXXXX.html fornecido pelo Google.
      - Envie o arquivo sem alterar o nome ou o conteúdo para a raiz
        do repositório, ao lado do index.html.

   B) Tag HTML
      - Copie exatamente a meta tag fornecida pelo Google.
      - Ela deverá ser colocada no <head> da Home.

4. Volte ao Search Console e toque em “Verificar”.

5. Depois da verificação, abra Sitemaps e envie:
   sitemap.xml

6. Use a Inspeção de URL para solicitar indexação primeiro destas
   sete páginas:
   https://divinabruxa.com.br/
   https://divinabruxa.com.br/cartas-do-tarot.html
   https://divinabruxa.com.br/tarot-livre.html
   https://divinabruxa.com.br/carta-do-dia.html
   https://divinabruxa.com.br/tiragens-de-tarot.html
   https://divinabruxa.com.br/escola-do-tarot.html
   https://divinabruxa.com.br/consultas-de-tarot.html

Não compartilhe senha. Para a próxima pequena versão, basta trazer
o arquivo HTML de verificação ou a meta tag exata do Google.

IMPORTANTE: um sitemap ajuda o Google a descobrir as páginas, mas
não garante indexação imediata nem uma posição específica. O Google
ainda precisa rastrear, processar e avaliar o conteúdo.
