DIVINA BRUXA — V59 BASE LIMPA DA ORBE E DO MENU

Este é um começo limpo para o novo repositório. O ZIP não contém pastas.
Envie todos os arquivos diretamente para a raiz do GitHub Pages.

Esta etapa entrega somente a Home visual: identidade, Orbe viva, dock e
Menu Mágico. Tarot, cartas, Escola, IA real, loja e consultas entram depois
da aprovação da Orbe e do menu.

ou deslocar enquanto a Orbe é tocada.

dependentes da configuração do novo repositório e não foram executadas aqui.
