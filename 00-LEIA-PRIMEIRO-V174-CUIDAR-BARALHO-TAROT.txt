COMO INSTALAR NO GITHUB PELO IPHONE

1. Descompacte o ZIP no aplicativo Arquivos.
2. Abra a raiz do repositório divinabruxa.github.io no ramo main.
3. Toque em Add file e Upload files.
4. Selecione os 14 arquivos soltos, não o ZIP.
5. Substitua estes 7 arquivos:
   - sitemap.xml
   - buscar.html
   - busca-v165.js
   - como-escolher-um-baralho-de-tarot.html
   - como-embaralhar-cartas-de-tarot.html
   - guias-para-comecar.html
   - escola-do-tarot.html
6. Adicione os outros 7 arquivos.
7. Não apague nenhum arquivo anterior.
8. Confirme o commit com a mensagem: Instala V174 cuidado do baralho
