ORBE DAS REALIDADES — PACOTE GITHUB SEM PASTAS

1. Abra este ZIP no aplicativo Arquivos do iPhone.
2. Toque em Descompactar.
3. Abra a pasta criada e selecione TODOS os arquivos.
4. No repositório GitHub, use Add file > Upload files.
5. Envie todos os arquivos juntos para a raiz.
6. Confirme em Commit changes.
7. Em Settings > Pages, selecione Deploy from a branch e a pasta /(root).

IMPORTANTE: não renomeie arquivos e não envie o ZIP diretamente como site. O ZIP serve apenas para transportar os arquivos.
