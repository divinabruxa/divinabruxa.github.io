COMO INSTALAR PELO IPHONE
============================================================

1. Baixe o arquivo:
   DIVINA-BRUXA-V155-SEARCH-CONSOLE.zip

2. Abra o aplicativo Arquivos e toque uma vez no ZIP para
   descompactar.

3. No GitHub, abra o repositório do site na pasta principal.

4. Toque em Add file > Upload files.

5. Selecione TODOS os 5 arquivos que estão dentro da pasta
   descompactada.

6. Envie os arquivos diretamente para a raiz, ao lado do app.js.
   Não crie nenhuma pasta nova.

7. Quando o GitHub avisar que index.html já existe, escolha
   substituir/atualizar o arquivo.

8. Use esta mensagem no commit:
   Instala V155 Google Search Console

9. Confirme o upload e aguarde a publicação do GitHub Pages.
