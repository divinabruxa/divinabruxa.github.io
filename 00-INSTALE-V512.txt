COMO INSTALAR NO GITHUB
1. Abra a raiz do mesmo site em que a V511 já está instalada.
2. Envie os 8 arquivos deste ZIP diretamente para a raiz.
3. Não crie pasta para eles: os arquivos precisam ficar soltos.
4. Confirme a substituição destes 3 arquivos:
   - app-v208.js
   - page-loader-v1.js
   - sw.js
5. Os outros 5 arquivos são novos:
   - 00-INSTALE-V512.txt
   - ORBE-OS-TAROT-LIVRE-V512-CONTRACT.json
   - tarot-livre-orbe-os-v512.js
   - tarot-livre-orbe-os-v512.css
   - tarot-cosmos-v512.webp
6. Aguarde o GitHub concluir e abra o site novamente.
7. Se o iPhone mantiver a tela anterior, feche a aba/app uma vez e abra de
   novo para o service worker V512 assumir.
